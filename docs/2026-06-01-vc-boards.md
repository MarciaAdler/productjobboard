# VC Portfolio Job Boards — 2026-06-01

## Goal

Add jobs from VC firm portfolio job boards for: a16z, Sequoia Capital, Insight Partners, Techstars, Pear VC, Boost VC, and Primary Venture Partners.

## Platform research

Before implementation, each board's platform was identified:

| VC Firm | Board URL | Platform | API Accessible? |
|---|---|---|---|
| a16z | jobs.a16z.com | Consider | No — JS SPA, no public API |
| Sequoia | jobs.sequoiacap.com | Consider | No — JS SPA, no public API |
| Insight Partners | jobs.insightpartners.com | Getro | No — requires OAuth (401) |
| Techstars | jobs.techstars.com | Getro | No — requires OAuth (401) |
| Pear VC | — | — | No board found |
| Boost VC | — | — | No board found |
| Primary VC | jobs.primary.vc | Getro | No — requires OAuth (401) |

### Consider (a16z, Sequoia)
Fully client-side rendered React SPA. No `__NEXT_DATA__` SSR payload, no JSON API, no RSS. The only way to scrape would be a headless browser executing their JavaScript. Not implemented — too heavy a dependency for an MVP.

### Getro (Insight Partners, Techstars, Primary VC)
Getro's job board API at `api.getro.com/v2/networks/{slug}/jobs` returns HTTP 401 for all slug patterns tested (requires API key + OAuth token). The board HTML is also client-side rendered — no job data in page source.

A `getro.ts` scraper was implemented that tries both approaches (direct API + `__NEXT_DATA__` HTML parse) and returns `[]` gracefully when both fail. The scraper is wired up and will automatically start working if Getro ever opens their API or if the HTML rendering strategy changes.

### Pear VC / Boost VC
No portfolio job board found at any tested URL. Boost VC is a pre-seed accelerator without a public job aggregation board. Pear VC's jobs section appears to be a bespoke founder service rather than a public portfolio board.

## What was implemented instead

Since the VC board platforms don't expose public APIs, portfolio companies were sourced directly from the underlying ATS boards (which do have public APIs):

### Verified portfolio company slugs added to Greenhouse

| Company | VC Backer | Greenhouse Slug | PM Jobs |
|---|---|---|---|
| Databricks | a16z | `databricks` | 25 |
| Instacart | Sequoia | `instacart` | 11 |
| Justworks | Primary VC | `justworks` | 6 |

Slugs tested and confirmed non-functional (wrong ATS or 0 jobs):
- `doordash` — DoorDash uses a custom ATS, not Greenhouse
- `gainsight` — Insight Partners portfolio, wrong slug or migrated
- `g2` — Insight Partners portfolio, not on Greenhouse
- `mux`, `cabal` — a16z portfolio companies, no PM roles or wrong ATS

### Net result
+42 PM jobs from VC portfolio companies (databricks 25 + instacart 11 + justworks 6). Total board went from 486 → 517 US/remote PM roles.

## What's needed to access VC board platforms directly

| Platform | Path to access |
|---|---|
| **Getro** | Register at getro.com for a developer API key, then use `GET https://api.getro.com/v2/networks/{id}/jobs?keywords=product+manager` |
| **Consider** | No documented public API; requires headless browser (Playwright) with `await page.waitForSelector('.job-card')` pattern |
| **Both** | Could also enumerate all portfolio companies from public VC websites and batch-query their individual ATS boards |

## Architecture note

The `getro.ts` scraper is kept active in `scrapers/index.ts`. It will silently return `[]` when auth fails, and will automatically surface jobs if the API becomes accessible or if a network ID + bearer token is ever provided via environment variable.
