# Updates — 2026-06-04

## Summary

Added Rippling ATS scraper, industry tags + filter, improved job description display, tightened US/remote location filtering, added Jobicy and We Work Remotely as global-search sources, and broadened the role filter to include all product roles (not just PM).

---

## New scraper: Rippling ATS (`server/src/scrapers/rippling.ts`)

- **API:** `https://ats.rippling.com/api/v2/board/{slug}/jobs` (list) + `../jobs/{uuid}` (detail)
- No auth required; public API
- Salary pulled from `payRangeDetails[0].rangeStart` / `rangeEnd`; falls back to `extractSalaryFromText`
- Company description and role description are separate HTML fields (`description.company`, `description.role`)
- 60+ verified company slugs in `RIPPLING_COMPANIES` in `server/src/constants/companies.ts`
- Added `'rippling'` to `AtsSource` union in both server and client types

---

## New scraper: Jobicy (`server/src/scrapers/jobicy.ts`)

- **Endpoint:** `https://jobicy.com/api/v2/remote-jobs?tag=product&geo=usa&count=50`
- Global-search API — no company slug list needed
- Returns US-only product roles; salary fields are `salaryMin` / `salaryMax` (yearly USD)
- HTML descriptions parsed via `htmlToText`
- Currently ~8–16 PM jobs depending on day; includes companies like Reddit, Meta, Five9, Life360

---

## New scraper: We Work Remotely (`server/src/scrapers/weworkremotely.ts`)

- **Feed:** `https://weworkremotely.com/categories/remote-product-jobs.rss` (RSS/XML)
- Global-search feed — no company slug list needed
- Title format is `"Company: Job Title"` — company name parsed by splitting on first `": "`
- Location from `<region>` tag; "Anywhere in the World" treated as global remote
- No salary data available
- Currently ~8–9 product roles (Toggl, JetBrains, Hint Health, Biggerpockets, Aledade, etc.)

## Industry tags

### `server/src/constants/industries.ts` (new file)

- Static map of ~150 company names (lowercase) → industry string
- Industries: AI/ML, Analytics, Enterprise SaaS, HR Tech, FinTech, Developer Tools, Cybersecurity, Infrastructure, Productivity, SaaS, Consumer, E-commerce, Real Estate, HealthTech, EdTech, Climate Tech, Media, Logistics, BioTech
- `getIndustry(companyName)` does exact match first, then partial match

### `server/src/scrapers/index.ts`

- Post-processing pass after deduplication: `job.industry ?? getIndustry(job.company)`
- All scrapers return `industry: null`; enrichment happens centrally

### `client/src/components/JobCard.tsx`

- Industry pill rendered next to company name on each card (only when non-null)
- Style: `bg-slate-100 text-slate-500 text-xs rounded-full px-1.5 py-0.5`

### `client/src/components/IndustryFilter.tsx` (new file)

- Dropdown filter following same pattern as `LocationFilter`
- Options built dynamically from actual job data, sorted by count
- Added to sticky filter bar in `App.tsx`

## Job description improvements

### `server/src/utils/normalizeJob.ts`

- Added `trimAtBoundary(text, maxLen)` — cuts at last paragraph break, then sentence boundary, then word boundary instead of hard character slice
- All scrapers updated: descriptions capped at 3000 chars, requirements at 1200 chars

### `client/src/components/JobDrawer.tsx`

- Added client-side `summarize(text, maxLen)` helper using same boundary logic
- Drawer shows: company summary (300 chars), requirements (700 chars), role summary (500 chars)
- "Read full job description →" link opens the apply URL

---

## Location filtering improvements (`server/src/utils/filterUS.ts`)

- Removed `ALWAYS_INCLUDE_SOURCES` bypass that let Remotive/RemoteOK skip all location checks
- Non-US country terms now checked **before** `isRemote` and state abbreviation checks
- Fixed "Bangalore, IN" (matched Indiana abbreviation before), "Remote (UK)", "Remote - Canada" false positives
- Only truly global signals (`worldwide`, `global`, `anywhere`, `wfh`) bypass the country check
- Expanded `NON_US_TERMS` to include Canada cities, LatAm countries, Middle East, Africa

### `server/src/scrapers/remotive.ts`

- Tightened `isUSOrGlobal` to reject any specific non-US country mention

## Role filter broadened (`server/src/utils/filterPM.ts`)

- Renamed `PM_PATTERNS` → `PRODUCT_PATTERNS`
- Added patterns for all product roles: `product designer`, `product design`, `product owner`, `product analyst`, `product scientist`, `product strategist`, `product operations`, `product ops`, `product marketing`
- Added `\bcpo\b` shorthand
- Removed `EXCLUDE_PATTERNS` (product designer / scientist exclusions added briefly, then removed per user request — all product roles are welcome)
- The board is now a **product job board**, not PM-only
